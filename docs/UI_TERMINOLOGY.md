# 界面术语对照

这些译法用于任务列表、编辑器和调度选项。已有任务名称、脚本路径及 API 响应正文按原内容显示。

| 语言 | 任务 | 定时 | 保活 | 托盘 |
| --- | --- | --- | --- | --- |
| zh-CN | 任务 | 定时 | 自动重启 | 系统托盘 |
| zh-TW | 工作 | 排程 | 自動重啟 | 系統匣 |
| en-US | Task | Schedule | Auto restart | System tray |
| ja-JP | タスク | スケジュール | 自動再起動 | 通知領域 |
| ko-KR | 작업 | 일정 | 자동 재시작 | 시스템 트레이 |
| de-DE | Aufgabe | Zeitplan | Automatischer Neustart | Infobereich |
| fr-FR | Tâche | Planification | Redémarrage automatique | Zone de notification |
| es-ES | Tarea | Programación | Reinicio automático | Área de notificación |
| pt-BR | Tarefa | Agendamento | Reinício automático | Área de notificação |
| ru-RU | Задача | Расписание | Автоперезапуск | Область уведомлений |

繁體中文採台灣用語，使用「腳本」「處理程序」「設定」「日誌」「預設」。
