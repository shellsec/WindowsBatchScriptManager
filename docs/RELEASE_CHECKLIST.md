# 1.3.0 发布检查

## 已核对

- 中英文完整说明、八种其他语言快速指南与十张运行截图互相链接。截图由真实程序渲染，任务与 IP 均为示例。
- Windows 发布方式为一个单文件 EXE 和一个 API 脚本。服务器继续使用已有的 Python 与 API 依赖。
- 主许可证为 Apache-2.0。保留早期 MIT 代码的版权与许可声明，参见 [LICENSE](../LICENSE)、[NOTICE](../NOTICE) 和 [LICENSE-MIT](../LICENSE-MIT)。
- 本机任务配置、API 配置、语言配置、执行历史和日志已在忽略规则中。公开发布前仍需复查待提交文件与 Git 历史。
- 构建方式、升级保留配置和双文件部署均已写入 README。

## 正式公开发布前

1. 核对最终 EXE 所含第三方库和 Windows 运行库的再分发条款及许可证附件，并确认项目贡献与外来代码的署名和授权。
2. 检查完整 Git 历史和发布附件是否含密钥、真实地址、用户配置或日志。
3. 用干净 Windows 环境测试双击启动、语言跟随、覆盖升级、API 与 MCP。发布时上传对应源码、ZIP 和 SHA-256 校验值。
4. 在对外开放 API 或 MCP 前，替换默认 API 密钥，限制监听与网络可达范围，并补齐 MCP 的 Origin 校验。

## 文件取舍

| 处理 | 文件 | 原因 |
| --- | --- | --- |
| 提交源码 | 主程序、API 脚本、任务功能模块、语言模块、构建脚本、依赖清单、图标、测试 | 用于运行、构建及验证 |
| 提交文档 | 十份 README、使用手册、术语表、示例截图、许可证与版权声明 | 用户上手和再分发所需 |
| 保留平台适配 | `macBatchScriptManager/`、`linuxBatchScriptManager/` | 根目录主程序引用其中的 `platform_impl.py`，各目录的 `main.py` 是轻量兼容入口 |
| 可选源码 | `web_dashboard.py`、`api_server.py`、API 启动批处理 | 分别提供可选 Web 面板及兼容入口，无需收入 Windows 运行包 |
| 本机使用 | 任务、API、语言、应用、通知、监控配置，执行历史、备份与日志 | 可能包含用户数据，已由忽略规则排除 |
| 本地可重建 | `build/`、`.venv-build/`、`__pycache__/` | 构建中间产物、虚拟环境和缓存 |
| 单独归档 | `dist/` 内旧 EXE、旧 ZIP 和排障构建，`docs/superpowers/` 内实施计划与设计草稿 | 供本地回滚或复盘，正式发布只选对应版本的 ZIP 和校验值 |

本次核对了可达的 3 个 Git 提交，常见私钥、GitHub 令牌、AWS 访问密钥和 OpenAI 项目密钥格式的初筛没有匹配。当前 1.3.0 ZIP 已检查文件清单，含一个 EXE、一个 API 脚本和许可证附件。这次初筛覆盖指定格式，正式发布前仍需复核待提交文件和历史内容。
