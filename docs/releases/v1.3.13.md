## v1.3.13

### License change

The combined project is now **AGPL-3.0-only**. Commercial use is allowed. Redistribution and modified deployments that interact with users over a network carry corresponding-source obligations. This does not mean every private modification must be published on GitHub. Earlier releases keep their previously granted licenses; mandatory historical and third-party notices are retained.

Source is attached as `WindowsBatchScriptManager-1.3.13-source.zip`, with build configuration, tests and license notices. See `THIRD_PARTY_NOTICES.md` for the provenance/dependency review and its scope. Reviewed dependencies did not reveal a licensing conflict; this is not a certification of every historical code origin or every optional installed extra.

### MCP and documentation

- Added read-only `get_task_logs` and `get_task_result`: bounded saved-log reads and latest recorded execution results. Exact IDs or unique exact names are required; missing/stale records are explained. Update both the API script and manager EXE.
- Added `/source`, MCP `get_source_info`, and a corresponding-source link on the API landing page.
- Replaced actual API keys in public documentation examples with a placeholder.
- Added enterprise Windows use cases, pain points and operating boundaries to English and Simplified Chinese README files; all ten README files include synchronized use-case, MCP, cleanup and licensing information.
- Task scheduling/execution and the independent SSH/SFTP maintenance architecture are unchanged.

### Downloads and validation

- Standalone single-file EXE, Windows ZIP, source ZIP and SHA-256 checksums.
- Project and third-party notices are embedded in the EXE and included in the ZIP. The independent API script still needs Python and its dependencies.
- Reuses the previous offline OpenSSH 10.4.0.0 installer, officially labeled **10.4.0.0p1-Preview**, with its published SHA-256 verified and original notices retained.
- 55 automated tests pass. Compiled CLI diagnostics and embedded-license checks were also performed before publication.
